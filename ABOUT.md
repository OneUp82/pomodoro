# ℹ️ Om Prosjektet / About

## 🥑 Pixel Mascot Pomodoro

En sjarmerende og leken skrivebords-maskot og Pomodoro-timer bygget i Python.

---

### 👤 Utvikler
- **Laget av:** [OneUp82](https://github.com/OneUp82)
- **GitHub Profil:** [https://github.com/OneUp82](https://github.com/OneUp82)

---

### 🌟 Høydepunkter og Funksjoner

1. **🥑 10 Søte Pixel Art Skins**:
   - Avokado, Katt, Hund, Frosk, And, Panda, Robot, Spøkelse, Jordbær og Bjørn.
2. **🔊 Unik Lyd for Hvert Skin**:
   - Katten mjauer, hunden bjeffer, avokadoen lager tegneserie-pop, roboten piper 8-bit, osv.
3. **🖱️ Interaktiv og Flytende**:
   - Ingen firkantede vindusrammer – figuren flyter fritt på skrivebordet.
   - Kan dras rundt hvor som helst med venstre museknapp.
4. **📳 Risteeffekt (Screen Shake)**:
   - Når timeren når `00:00:00`, vibrerer maskoten ivrig på skjermen for å feire!
5. **📏 Flere Størrelser**:
   - Velg mellom Liten, Medium (standard), Stor og Ekstra Stor via høyreklikk.
6. **🛡️ Sikker og Robust Kode**:
   - Inndatavalidering for timer, minutter og sekunder uten usikre funksjoner.

---

### 💻 Teknologier
- **Programmeringsspråk:** Python 3.12+
- **Brukergrensesnitt:** `Tkinter` (med transparent fargenøkkel og Canvas)
- **Grafikk og Pikselbehandling:** `Pillow` (PIL) med Nearest Neighbor-skalering
- **Lyd:** `pygame.mixer` med Windows `winsound` som reserve
- **Lydsyntese:** Pythons standard `wave`, `math` og `struct`
